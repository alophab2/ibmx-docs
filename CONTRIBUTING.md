# Contributing to ibmx-docs

Thank you for your interest in contributing to **ibmx-docs**! This repository aims to provide a comprehensive open-source knowledge base, cheat sheets, and practical automation scripts for the global IBM i (AS/400) community.

---

## 🛠 How You Can Contribute

You can help improve this project in several ways:
1. **Expand Documentation**: Add or refine CL/SQL command definitions in `cheat-sheets/`.
2. **Share Operations Scripts**: Submit useful SQL/CL automation scripts to `scripts/`.
3. **Report Issues**: Open an issue if you spot errors or need missing commands/scripts.
4. **Review PRs**: Help review community pull requests and validate solutions.

---

## 🚀 Pull Request Workflow

1. **Fork the repository** by clicking the `Fork` button at the top right of this page.
2. **Clone your fork** locally:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/ibmx-docs.git](https://github.com/YOUR-USERNAME/ibmx-docs.git)
   cd ibmx-docs
